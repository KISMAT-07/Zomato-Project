# Zomato Restaurant Reviews Analysis

This project analyzes Zomato restaurant reviews and metadata using Data Science and Machine Learning techniques. It includes data cleaning, exploratory data analysis, hypothesis testing, preprocessing, sentiment modeling, and a final presentation.

## Project Files

- `Sample_ML_Submission_Template.ipynb` - completed notebook in the required submission template
- `Zomato_Project_Final_Submission.ipynb` - final backup copy of the completed notebook
- `Zomato Restaurant reviews.csv` - raw review dataset
- `Zomato Restaurant names and Metadata.csv` - raw restaurant metadata dataset
- `data/zomato_cleaned_step1.csv` - cleaned dataset
- `data/zomato_preprocessed_step4.csv` - preprocessed dataset for machine learning
- `data/ml_model_results.json` - saved model evaluation results
- `models/zomato_sentiment_model.joblib` - trained sentiment model
- `outputs/zomato_final_presentation.pptx` - final project presentation
- `requirements.txt` - Python libraries required to run the notebook

## How To Run

1. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

2. Open `Sample_ML_Submission_Template.ipynb` in Jupyter Notebook or VS Code.

3. Run the notebook cells from top to bottom.

## Main Objective

The goal of this project is to understand restaurant review patterns, clean and prepare text data, build a sentiment analysis model, and present useful business insights from Zomato review data.
